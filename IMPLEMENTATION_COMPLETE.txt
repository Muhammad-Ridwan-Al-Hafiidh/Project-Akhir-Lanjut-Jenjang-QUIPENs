================================================================================
                          HOW IT WORKS
================================================================================

QUIZ CREATION:
  1. Admin goes to /quiz/create
  2. Selects 1+ topics from dropdown (e.g., "Jaringan Komputer", "Struktur Data")
  3. Sets quiz parameters (duration, pass score, etc.)
  4. Saves - topics are inserted into quiz_topics table

QUIZ ATTEMPT:
  1. Student starts quiz
  2. System calls: WorkoutService::setWorkOutQuizSyncForThisExcersice()
  3. Service:
     - Gets selected topics from quiz_topics
     - Queries questions matching those topics
     - Applies difficulty filter (if DDA)
     - Stores selected questions in workout_quiz_logs
  4. Frontend loads questions from workout_quiz_logs
  5. All displayed questions GUARANTEED to match selected topics

DDA MODE:
  1. Student answers questions
  2. Each answer has topic recorded
  3. On "Next Difficulty" request:
     - DDA service analyzes by topic
     - Recommends difficulty specific to topic
     - RL agent uses per-topic level state
  4. Next questions selected from same or related topics
